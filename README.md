# Bunny-Character-Animation
Bunny Character Animation Using Adobe Animate

The project titled “Cute Bunny Character Animation Using Adobe
Animate” focuses on designing and animating a cartoon bunny
character using 2D animation techniques. The objective is to create an
appealing character and use animation concepts to give it movement
and expression.
The character is designed with a white body, pink ears, cheeks, paws
and facial details, presented against a light pink background. Adobe
Animate is used to organise the artwork and create animation through
the timeline, layers, frames, keyframes and Classic Tween where
applicable.
The project provides practical experience in character construction,
animation planning and previewing a 2D animation.
